#### 🔐 [Phishing Detection System](https://github.com/Sohamgor1904/Phishing_Detection_System)
> Python · Scikit-learn · Pandas · XGBoost · Random Forest

- Built an end-to-end ML pipeline to detect phishing websites using the **PhiUSIIL dataset (~235k rows)**
- Engineered URL-based features: length, IP presence, protocol type, shortener detection, and more
- Evaluated 9 models including **Random Forest, XGBoost, Gradient Boosting, Voting & Stacking classifiers**
- Achieved **near-perfect accuracy (up to 1.0)** on test set; tuned best model via `GridSearchCV`
- Includes real-time prediction interface to classify new URLs instantly
